# barcodeEZ

**barcodeEZ** is a python package enabling construction of complex barcode libraries. Users may create a `Barcodes` object, which is site-aware and supports flexible building of combinatorial barcoded sites or positions. Raw barcode sequence is sourced from a prebuilt corpus of orthogonal sequence (provided with the package). The package enables users to design a structure, generate barcodes, visualize the design, validate against unwanted sequence content, and output an order form to obtain the finalized library as single-strand oligos.
